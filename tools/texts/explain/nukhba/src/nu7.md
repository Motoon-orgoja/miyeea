# الْمُحْكَمُ وَمُخْتَلِفُ الْحَدِيثِ وَالنَّاسِخُ وَالْمَنْسُوخُ
(الْمَقْبُولُ)

[1] ثُمَّ المَقْبُولُ: إِنْ سَلِمَ مِنَ المُعَارَضَةِ: فَهُوَ المُحْكَمُ. وَإِنْ عُورِضَ بِمِثْلِهِ: فَإِنْ أَمْكَنَ الجَمْعُ: فَهُوَ مُخْتَلِفُ الحَدِيثِ. أَوْ ثَبَتَ المُتَأَخِّرُ: فَهُوَ النَّاسِخُ، وَالآخَرُ المَنْسُوخُ، وَإِلَّا فَالتَّرْجِيحُ، ثُمَّ التَّوَقُّفُ.
